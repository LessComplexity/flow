## Decisions made (beyond the ADR's letter — all recorded in the plan's As-built section)

1. **Guard-arm codes as-built:** clean guard token in a seq body → **P0004** (stray
   guard); spaced/pattern arms → **P0005/P0106**, **+P0006 when mixed with statements**.
   The ADR's original "P0006-illegal" wording was mechanism-impossible for clean guards;
   ADR Decision paragraph annotated, ERRATA LC-5 worded precisely, both P0004 and P0006
   paths regression-tested.
2. **P0117 fires on `void` blocks only** (a rebind/loop in a Plain fanout reclassifies to
   P0115 upstream); pushed **directly** onto diagnostics — the `self.diag` cooldown at a
   settled cursor collapsed multi-drop reporting to one (review blocker, fixed,
   `fanout_block_each_dropped_stmt_draws_p0117`).
3. **Void-block tail kept:** the final `;`-less chain in `void { … }` was silently
   discarded (pre-existing) — now a branch.
4. **L1611 `SeqNoValue`** over parameterizing L1305; new **`ChainCtx::RetValue`** makes
   the return-position no-tail guarantee hold for **effectful** fns too (was falling
   through to L1306).
5. **Walker sweep fixed three PRE-EXISTING live miscompiles** (found hunting SeqBlock
   gaps; the `Fanout` siblings had the same holes): the Phi-arm scanner (`scan_chain` —
   effectful fanout/seq in a Phi arm was hoisted **unconditionally**, L1404 bypassed,
   validate-clean wrong IR); the loop carried-set collector (`collect_assigns_chain` — a
   `mut` reassigned in a fanout/seq inside a loop body dropped from carried state); the
   capture check (`capture_chain` — L1108 misreported as L1101). Each has a named
   regression; `sum_to_n_seq_wrapped_reassign_value_contract` pins 55 via the oracle.
6. **seq_demo.flow** added as a new example (not a fanout.flow extension) — wired into
   the same golden harnesses as zip_demo across all four crates.
7. **Deliberately NOT fixed** (recorded, lower suggestions.md row 2 / global row 6): a
   value-less **Fanout** in an effectful fn's return position still draws generic L1306
   (pre-existing; the RetValue seam was applied to seq only, per WP scope).
