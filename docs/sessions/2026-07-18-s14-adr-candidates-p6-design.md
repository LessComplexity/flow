## 2. Decisions

| Decision               | Verdict                                                                                                                                                      | Why                                                                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| CUDA execution mapping | host/device split: scalars+IO+loop-driving host; array-bulk ops → kernels (launch form top-level, inline form in bodies)                                     | uniform residency ⇒ zero whole-array D→H by construction (BC1; arrays are unprintable, L1207)                                                   |
| `Fold` on GPU          | **sequential everywhere** (single-thread kernel when device-resident)                                                                                        | oracle folds left (`eval.rs:218–231`); f32 non-associativity breaks tree reductions under R1; arbitrary-body associativity is undecidable (BC4) |
| Parallel float `Fold`  | recorded as **ADR candidate for Sapir** (oracle re-pin) — NOT a backend choice                                                                               | the oracle is the final arbiter (ADR-0022 D1 rank 1); changing it changes the language                                                          |
| Buffer ownership       | **allocation-based** (per-fn allocation registry; parameters borrowed; returns escape via caller-frees; no-double-free / no-use-after-free invariants)       | review OF-2: "free every live handle" miscompiles under aliasing                                                                                |
| CUDA infra errors      | every API call asserted + `cudaGetLastError()` per launch ⇒ **exit 102**, harness-visible infra failure                                                      | never an R1 data point (HW-2 ≡ CC-1b)                                                                                                           |
| Index arithmetic       | 64-bit throughout (`size: u64` in `Ty`)                                                                                                                      | review HW-3: 32-bit grid products overflow                                                                                                      |
| Fn qualifiers          | three-case rule (token-bearing ⇒ host-only; body-reachable ⇒ inline both sites; launch-form ⇒ host-only; only pure-scalar fns dual-qualified)                | review HW-1: the two-case draft emits illegal CUDA (CDP/rdc)                                                                                    |
| Bounds-guard width     | llvm rule pinned: extend per `Ty` to `int64_t` (zext/sext), signed two-sided compare, never `size_t`                                                         | review OF-3 (the S13 u8 class)                                                                                                                  |
| Wrapping ints          | unsigned casts in C++                                                                                                                                        | C++ signed overflow and `INT_MIN÷-1` are UB where LLVM no-`nsw` is defined (BC2)                                                                |
| Traps                  | `cudaMalloc`'d flag, host check after **every** launch (class parity + first-trap-wins)                                                                      | BC6; sync-per-launch is the correct-first price                                                                                                 |
| Floats                 | `-fmad=false` (device), ISO `-std=c++17` host with `-march=native`/`-mfma` **forbidden**                                                                     | nvcc default contraction changes bytes vs the oracle (BC9, HW-4)                                                                                |
| Harness                | full-remote `cargo test` on one vast.ai 4090 (45170851); devel image, preflight, 15 s run / 120 s compile timeouts, wall-time envelope with abort-and-record | BC10; the ADR-0020 §4 duty stays definition-identical to llvm's                                                                                 |
| M3 claims              | correctness only — no perf numbers, no "GPU is faster"                                                                                                       | VISION truth #1; perf claims await the array-scale-plan ladder                                                                                  |
