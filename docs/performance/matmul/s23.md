## Kernel decomposition (FLOW_PERF, N=512 f32)

0.318 total = 0.155 module load (first launch, one-time) + **0.125 the GEMM kernel (k0_4)** + 0.038 iota/fill/readback kernels. Remaining k0_4 gap to naive-CUDA (1.6×): `-fmad=false` (oracle-pinned, Sapir's open call) + untuned geometry (256/block).

## Verification

`c[0]`/`c[N²−1]` agree across flow-cuda, flow-llvm, naive-CUDA, cuBLAS, rust, cpp, chapel, numpy at every shared N (1047/2107 @64 · −7312/−933 @128 · −3694/10946 @256 · −22592/−38634 @512 · 11107/91690 @1024). flow oracle-pinned at N=4/16/32. Remote cuda differential **15/15 green** on this box over the S22+WP-D emitters (first attempt's 3 "divergences" = 15 s timeouts under 48-way fan-out; 16-core pinning fixed — zero real).

## Method

RTX 4090, 48 vCPU znver3 · nvcc 12.4.131 (`-fmad=false -arch=sm_89`) · clang 15 (`-O2 -march=native`) · Chapel 2.9.0 CPU locale (`--fast`, post-sweep append) · rust 1.97.1 · numpy pip. One box for all legs. CPU legs move with the box's CPU — compare within one session file only (S21's llvm-beats-cpp reversed here on znver3).
