# ADR-0022: Truth in docs — the as-implemented index, retirement of "frozen", and the Level-B maintenance freeze

Date: 2026-07-18 · Status: accepted — **ratified by Sapir 2026-07-18 (S14)**, D2 amended at ratification (see the amendment markers in D2 and the Ratification note at the end)

## Context (what forced the decision; spec refs)

The 2026-07-18 eight-dimension honest review surfaced three governance findings the current docs obscure:

**(a) "Frozen Level-A spec" is a fiction of text.** HANDOFF §1 declares "the spec is frozen at v0.2 + errata"; the ERRATA.md preamble repeats it. The ledger contradicts the adjective: 31 normative entries in the five-plus weeks since the 2026-06-11 freeze — 21 ADRs (ADR-0001…0021), errata E1–E5, living corrections LC-1–5. The operative semantics live in the ADR stack, not the v0.2 files: guard-first loops (ADR-0016), the print/println split (ADR-0015), zip/enumerate (ADR-0018), `seq` statement blocks (ADR-0019/LC-5), the backend emission contract (ADR-0020), array `Update` (ADR-0021). HANDOFF §2.2 already ranks ADRs above the corpus, but the "frozen" framing still tells a reader to start from the v0.2 text — a language that no longer exists.

**(b) The Level-B categorical methodology has ratified decisions but zero discovered bugs.** FRAMEWORK.md + `docs/architecture/` (ADR-0014; docs tree ADR-0017) mandate a `## Categorical model (Dat + Trn)` section per component DESIGN (HANDOFF §7.1.5) and a per-session reconcile gate (HANDOFF §7.2 step 7: FRAMEWORK §8 checklist + model/INDEX upkeep in the same change). The review's ledger: every real defect found to date came from testing or adversarial review — E1–E5 from the formal v0.2 review, LC-1–5 from use and spec review, the S11–S13 findings (the `seq` parse failure LC-5, the missed replay `Update` arm, the indexed-rebind wiring) from implementation and adversarial passes. The Level-B apparatus has found none while costing full sessions of upkeep. Its value as a record of ratified decisions stands; its value as a bug-finding gate is unproven.

**(c) VISION.md's competitive claims needed factual correction** — the O4 "no incumbent makes this claim" cell and the missing related-work citations (Compiling to Categories, DaCe, Vericert, Halide's formal semantics, Futhark, SCADE/CompCert) — corrected in the same 2026-07-18 mitigation pass.

## Decision (imperative)

1. **D1 — `docs/spec/flow-as-implemented.md` is the operative index of the language; "frozen" is retired.** The explicit authority order (highest wins): **oracle (interpreter) behavior is the final arbiter** (HANDOFF §5.4; ADR-0020 §3); within text, **newest wins** — accepted ADRs over living corrections LC-1–5 over errata E1–E5 over the v0.2 corpus. `flow-as-implemented.md` (dated 2026-07-18, authored in the same pass) indexes that stack into one readable document, citing the ADR behind each delta; it makes no normative claims of its own — where its summary and the stack disagree, the stack wins and the index is patched. The word "frozen" is retired wherever it describes spec authority (HANDOFF §1, §2.2, closing — patched in this change; the ERRATA.md preamble carries the same stale sentence and is flagged in §"Spec impact" below). Scope uses of the word are restated as "fixed" so the vocabulary keeps a single meaning.

2. **D2 — Level-B FRAMEWORK maintenance is frozen until it finds its first bug.** Suspended, effective this date: the mandatory `## Categorical model (Dat + Trn)` lead section for new component DESIGNs (HANDOFF §7.1.5), the per-session reconcile-gate upkeep (HANDOFF §7.2 step 7's first bullet — the FRAMEWORK §8 checklist verification plus model/morphism-table/`docs/architecture/INDEX.md` update in the same change), and all new Dat/Trn modeling. **Exception (amended at ratification 2026-07-18):** a backend-seam decision that explicitly invokes the FRAMEWORK (the `F_LLVM`/`F_CUDA`/`F_Verilog` realization-contract class reserved in categorical-model §7.5) pays its modeling cost locally, **in that backend's DESIGN** — and for new backends this exception is **standing practice, not case-by-case** (the S14 evidence supports exactly this scope; see the Ratification note). Existing models stay in place and bind where present — they are demoted from gate to reference, not deleted; drift from code is now expected and tolerated, and is not a defect to be reconciled. **Re-evaluation trigger (amended at ratification):** full upkeep resumes only if the Level-B apparatus catches a real defect **outside backend seams**. The trigger's original letter fired at first use — S14, the backend-cuda D2 keep-test found the §2 transfer inventory incomplete (3 missing crossings; `docs/components/backend-cuda/reviews/review-design-p6.md`) — and was judged at ratification to support the backend-seam exception, not general upkeep. The bug-finding budget is unchanged and explicitly assigned to what has produced every bug so far: differential testing against the oracle (ADR-0020 §4), testgen, and adversarial review. **Not suspended:** the ADR-0017 session ledger (STATUS, next-session, sessions, IMPLEMENTATION.md rows — §7.2 step 7's second bullet stands) — the review indicted model upkeep, not the docs/ loop.

3. **D3 — The VISION.md related-work correction is ratified as factual maintenance, not a direction change.** The added citations and the corrected O4 cell narrow the *claim text* to what is true; O4 remains the chosen differentiator, and the E1 trace theorem remains the thesis-level correctness claim. Strategy is untouched.

## Non-goals (what this does NOT change)

- **Roadmap, M5, Flow-Core scope.** The thesis artifact (`examples/sepia.flow` on CPU/GPU/FPGA-sim), the milestone ordering, and the HANDOFF §4 subset are untouched. "Frozen" retired ≠ scope reopened: Core scope changes still require an ADR, exactly as before.
- **The ADR mechanism.** ADRs remain the only channel of normative change; D1 renames the frame, it does not add a channel. `flow-as-implemented.md` is an index *of* the stack, not a new layer *in* it.
- **The oracle's role.** Interpreter-as-oracle (HANDOFF §5.4, ADR-0020) is reaffirmed, not created, here.
- **Existing Level-B artifacts.** FRAMEWORK.md, `docs/architecture/`, and component Dat/Trn sections are not deleted or rewritten; FRAMEWORK remains the method of record whenever D2's exception is invoked.

## Consequences

Sessions get cheaper by the reconcile-gate upkeep cost, and the §7.2 step-1 read path gains one file: `flow-as-implemented.md` is now the fastest correct answer to "what does the language do today." Risks stated honestly: (i) the index can drift from the stack — mitigated by its standing rule (stack wins, index patched) and by its per-delta ADR citations; (ii) Level-B models will drift from code — accepted as the explicit price of D2, and if stale models ever threaten to mislead a backend-seam decision, that is exactly D2's exception case and the model gets locally refreshed in that ADR. If Sapir vetoes D2, the gates resume with zero code impact (nothing was deleted). If Sapir vetoes D1's framing, the v0.2+errata frame stands but finding (a) — the word "frozen" describing 31 entries of change — remains to be solved another way.

## Ratification note (2026-07-18, Sapir)

Ratified by Sapir on the orchestrator's recommendation, closing the S14 governance queue item. **D1 and D3 unchanged. D2 amended at ratification**, on the S14 evidence: the re-evaluation trigger's original letter ("frozen until it finds its first bug") fired at first use — the backend-cuda D2 keep-test (the contract-coherence lens found the §2 transfer inventory incomplete: 3 missing crossings; `docs/components/backend-cuda/reviews/review-design-p6.md`). Judgment recorded: the finding demonstrates the model's value as a *design-review checklist generator at backend seams* — the one place with a real physical boundary — not as per-component upkeep; therefore (i) general Level-B upkeep stays frozen, (ii) the backend-seam exception becomes **standing practice for new backends**, (iii) the trigger is reworded so full upkeep resumes only on a Level-B catch **outside backend seams**, and (iv) the modeling cost for a backend seam is paid **in that backend's DESIGN** (as backend-cuda's was), not necessarily in a new ADR. The ERRATA.md preamble was patched in this same change. HANDOFF's D2 markers (§2.1, §2.2, §7.1.5, §7.2 step 7) reference this ADR generically and required no repatching. The ADR-0023/24/25 candidates are unaffected — they remain undecided, their numbers provisional.
